## 2. 세계관 & 스토리

### 배경
2045년, 대한민국 인구가 3,500만 명 아래로 떨어지며 국가 존립 위기에 직면한다.
정부는 최후의 수단으로 **"복제인간 양산 프로젝트"**를 가동하고,
이를 전담할 신설 기관 **"신인류청"**을 설립한다.

### 주인공
- **직책**: 신인류청 차장 (실질적 실무 총괄)
- **역할**: 복제인간 생산, 예산 관리, 사회적 갈등 해결, 청장 뒷수습
- **성격**: 플레이어가 선택지를 통해 결정 (냉소적 / 이상주의적 / 관료적)

### 청장
- 대통령 친인척으로 낙하산 부임
- 주로 골프, 해외 출장(놀러감), 기자회견(헛소리)에 바쁨
- 가끔 돌발 지시를 내려 플레이어를 곤란하게 함
- 공은 자기가 가져가고, 실패는 차장에게 떠넘김

## 3. 핵심 게임 루프

```
[예산 배정] → [복제인간 생산] → [사회 배치] → [이벤트 발생] → [대응/해결]
     ↑                                                          ↓
     ←←←←←←←←←← [결과 반영 (여론/예산/인구)] ←←←←←←←←←←←←←←←←
```

### 턴 구조
- **1턴 = 1개월** (게임 내 시간)
- 매 턴마다: 예산 배정 → 생산 → 이벤트 처리 → 월간 보고
- **목표**: 2045년부터 2080년까지 (420턴) 인구 목표 달성

## 4. 핵심 시스템

### 4.1 복제인간 생산 시스템

| 등급 | 이름 | 생산 비용 | 생산 기간 | 품질 | 설명 |
|------|------|----------|----------|------|------|
| D등급 | 급속복제체 | 5억 원 | 1개월 | 낮음 | 수명 짧고 능력치 낮음, 사고 확률 높음 |
| C등급 | 표준복제체 | 20억 원 | 3개월 | 보통 | 일반 시민 수준, 단순 노동 가능 |
| B등급 | 강화복제체 | 50억 원 | 6개월 | 높음 | 전문직 투입 가능, 학습능력 우수 |
| A등급 | 정밀복제체 | 200억 원 | 12개월 | 매우 높음 | 거의 완벽한 인간, 구별 불가 |
| S등급 | 초월복제체 | 1000억 원 | 24개월 | 극상 | 인간 이상의 능력, 윤리적 논란 극대화 |

**생산 실패 확률**: 등급이 낮을수록 결함 발생률 증가
- D등급: 30% 결함률 → 사회 문제 유발
- S등급: 2% 결함률 → 하지만 실패 시 대형 사고

### 4.2 자원 관리

| 자원 | 설명 |
|------|------|
| **예산** (억 원) | 정부 배정 + 복제인간 경제활동 세수 |
| **여론 지지율** (%) | 50% 이하로 떨어지면 시위 빈도 증가, 20% 이하면 게임오버 |
| **기술 레벨** (1~10) | R&D 투자로 상승, 생산 품질·속도에 영향 |
| **청장 기분** (😊~😡) | 낮으면 돌발 지시 빈도 증가, 높으면 예산 추가 획득 |
| **윤리 게이지** (0~100) | 비윤리적 선택 시 감소, 0이면 국제 제재 → 게임오버 |
| **현재 인구** (명) | 게임의 궁극적 목표 수치 |

### 4.3 사회 배치 시스템
복제인간을 사회 각 분야에 배치:

| 분야 | 효과 | 리스크 |
|------|------|--------|
| **제조업** | 경제 성장, 세수 증가 | 노동자 반발, 일자리 갈등 |
| **군대** | 국방력 강화, 정부 지지 상승 | 국제 사회 비난, 윤리 게이지 감소 |
| **의료** | 복지 향상, 여론 상승 | 의료 사고 시 큰 타격 |
| **연구** | 기술 레벨 상승 | 복제인간 자아각성 리스크 |
| **출산 장려** | 복제인간끼리 가정 구성 | "진짜 가족인가" 논란 |
| **정치** | 정책 지지 확보 | 복제인간 인권 운동 촉발 |

## 5. 이벤트 시스템

### 5.1 정기 이벤트 (매 분기)
- **국정감사**: 국회에 불려가 성과 보고 (선택지에 따라 예산 증감)
- **청장 기자회견**: 청장이 말실수 → 수습해야 함
- **분기 실적 보고**: 목표 대비 달성률 평가

### 5.2 랜덤 이벤트

#### 🔴 위기 이벤트
| 이벤트 | 설명 | 선택지 예시 |
|--------|------|------------|
| **반복제 시위대** | 시민단체가 청사 앞 점거 | ① 대화 시도 ② 경찰 투입 ③ 청장 내보내기 ④ 무시 |
| **복제인간 탈주** | D등급 복제체 집단 탈출 | ① 추적팀 파견 ② 언론 통제 ③ 자진 귀환 유도 |
| **윤리위 조사** | 국가윤리위원회 감사 | ① 투명 공개 ② 서류 조작 ③ 청장한테 떠넘기기 |
| **국제 제재 위협** | UN에서 경고장 발송 | ① 외교적 해결 ② 무시 ③ 로비 ④ 프로그램 축소 |
| **복제인간 자아각성** | A등급 이상이 "나는 누구인가" 질문 | ① 인권 인정 ② 기억 리셋 ③ 철학 상담사 배치 |

#### 🟡 일상 이벤트
| 이벤트 | 설명 |
|--------|------|
| **청장 골프 초대** | 따라가면 청장 기분↑, 업무 1턴 지연 |
| **복제인간 연애** | 복제인간끼리 커플 탄생, 여론 반응 갈림 |
| **TV 다큐 촬영** | 신인류청 다큐멘터리 제작, 여론 변동 |
| **복제인간 아이돌 데뷔** | 대중문화 진출, 여론 급상승 but 윤리 논란 |
| **명절 특집** | "복제인간도 세뱃돈을 받나요?" 논란 |

#### 🟢 기회 이벤트
| 이벤트 | 설명 |
|--------|------|
| **해외 기술 제안** | 외국에서 기술 거래 제안 |
| **천재 복제인간** | S등급에서 천재 탄생, 연구 부스트 |
| **여론 역전** | 복제인간이 재난 구조 활약, 지지율 급상승 |

### 5.3 청장 돌발 이벤트
| 이벤트 | 설명 |
|--------|------|
| **"복제인간 100만 만들어!"** | 비현실적 목표 하달 (예산도 안 줌) |
| **"내 강아지도 복제해줘"** | 사적 이용 요구 |
| **"기자회견에서 내가 다 했다고 해"** | 공 가로채기 |
| **"예산 좀 빼서 청사 리모델링하자"** | 예산 유용 시도 |
| **해외 출장 (하와이)** | 3턴 동안 부재, 그 사이 청장 결재 필요한 일 발생 |

## 9. 밸런스 기초 수치

### 시작 조건 (2045년)
- 인구: 3,500만 명
- 예산: 5,000억 원/년 (약 420억/월)
- 여론 지지율: 45% (반반)
- 기술 레벨: 1
- 윤리 게이지: 70

### 승리 조건 (2080년까지)
- 최소: 인구 3,500만 명 유지 (B엔딩)
- 목표: 인구 4,000만 명 이상 (A엔딩)
- 이상: 인구 5,000만 명 + 윤리/여론 80+ (S엔딩)

### 월간 인구 변동
- 자연감소: 약 -2만 명/월 (고령화로 인한 사망 > 출생)
- D등급 복제: +100명/시설 (시설당)
- C등급 복제: +50명/시설
- B등급 복제: +20명/시설
- A등급 복제: +5명/시설
- S등급 복제: +1명/시설
